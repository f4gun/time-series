## 01. Singapore Labour Force Participation Rate

- **Packages Used:** 'forecast', 'ggplot2'
- **Methods Used:** Holt Linear Trend Model, Holt's Damped Trend Model, Automated ARIMA, Multi-model forecast comparison with `ggplot2`.
